## Editing notes

- Open the spreadsheet URL above in the in-app browser.
- Use the name box at the upper left of Google Sheets to jump directly to cells such as `D2`, `E2`, etc.
- If multi-cell paste does not work, edit one cell at a time:
  - click the name box
  - enter a cell reference
  - press Enter
  - press Enter again to edit the cell
  - select existing content and type/paste the new value
  - press Enter to commit
